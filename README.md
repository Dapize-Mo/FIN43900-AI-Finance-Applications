# FIN 43900 — AI Finance Applications

Private working repository for FIN 43900 at Purdue University, Fall 2026.

## Purpose

This repository is the durable home for course planning, weekly work, lab artifacts, and project development. Work should be developed and tested locally, committed throughout the semester, and pushed to GitHub regularly.

Brightspace remains the authoritative source for assignment specifications, deadlines, required files, and submissions. The professor's class repository provides course materials and starter files.

## Working organization

Folders will be added when they contain real work:

- `weeks/` — weekly exercises and class artifacts
- `labs/` — durable outputs produced by labs
- `notes/` — course notes and planning
- `projects/` — project planning and working areas
- `docs/` — repository documentation and decisions

Project 1, Project 2, and the capstone may move into separate private repositories if their Brightspace instructions require or materially favor independent repositories.

## AI and evidence rules

- Submit the timestamped Edition A human baseline before using project-specific generative AI on a major project.
- Disclose every AI tool used and its purpose.
- Treat AI output as a hypothesis until it is independently tested.
- Preserve prompts, material outputs, checks, corrections, limitations, and visible executed results as required.
- Never submit a claim, number, recommendation, or code path that cannot be explained and defended.

## Security

Never commit passwords, API keys, tokens, credentials, private data, or local `.env` files. Use environment variables for credentials and document only empty variable names in `.env.example` when needed.
